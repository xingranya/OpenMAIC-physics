# 演示视频脚本

> 用于录制参赛演示视频。**目标时长 4 分 30 秒 ± 20 秒**，1920×1080 / 60fps。
> 现场演示脚本（8–10 分钟）见 `演示脚本.md`；本视频是它的浓缩版，
> 用于评委在评审前/评审后自行观看。

---

## 0. 录制参数

| 项 | 值 |
| --- | --- |
| 分辨率 | 1920 × 1080 |
| 帧率 | 60 fps（光标与滚动必须顺滑，掉帧会被判为"卡"） |
| 缩放 | 浏览器 100%，系统 125%（保证 1440p 下的文字可读） |
| 音频 | 麦克风录旁白；系统提示音关闭 |
| 字幕 | 后期添加，烧录进画面（无障碍要求） |
| 封面帧 | 第 1 镜的 3 秒（首页 + 校徽 + 门户） |
| 结束帧 | 第 12 镜的 3 秒（平台名 + 团队 + 二开致谢） |

**录制纪律**
- 只录真实操作，不做后期拼接。评委看得出剪辑痕迹，扣分远大于时长收益。
- 每一个界面停留 **≥ 2.5 秒**，让评委读完文字。
- 鼠标移动要慢，关键点击前**先悬停 0.5 秒**。

**录制前必须先过的两道门**（否则第 1 镜拍到的就不是首页了）

| 门 | 现象 | 处置 |
| --- | --- | --- |
| 平台访问保护（预设域名 `*.edgeone.dev`） | 打开后是**平台自己的** 401 页，不是我们的界面 | 用带令牌的地址打开一次（部署成功时 CLI 打印的地址带 `?eo_token=…&eo_time=…`）；平台下发 Cookie（3 小时）后裸地址即可 |
| 我们的访问码弹框 | 盖在首页上的弹框，副标题「长江大学文理学院 · 大学物理 AI 智慧课堂」 | 填入访问码提交，弹框消失后再开始录制 |

> 第 1 镜要的就是「首页 + 校徽 + 门户」，**弹框不能进画面**——
> 它是访问控制，不是产品界面。若误拍进去，只能重录（不做后期裁剪）。
>
> 弹框若报「请求未到达服务端（网络异常，或被平台访问保护拦截）」，
> 说明请求被平台 302 拦了或当时断网，**不是访问码错了**——
> 先用上面的带令牌地址打开，别去反复换码。

## 2. 旁白全文（约 620 字，可按语速微调）

> **[1]** 长江大学文理学院，《大学物理》AI 智慧课堂。我们基于清华大学开源项目 OpenMAIC 二次开发。
>
> **[2]** 平台有两条动线：AI 智能课堂负责"把课讲活"，物理学习工作台负责"把过程看清"。
>
> **[3]** 从登录开始。
>
> **[4]** 先做 8 道题的课前诊断，覆盖七个知识维度。诊断不是为了打分，是为了让后面的推荐有依据。
>
> **[5]** 右侧是各维度得分。注意下面那张可访问数据表——屏幕阅读器用户和打印出来的人，都能读到具体数字。
>
> **[6]** 项目匹配不是黑箱。每个项目都给出可读的理由：覆盖薄弱维度、符合学习方式、适合补强基础。
>
> **[7]** 任务分五阶，从情境认知到协同创生，每一阶都留过程证据。
>
> **[8]** 虚拟实验是超声测距。改噪声再跑一次，看相对误差怎么变。这个实验的价值是"说清误差从哪来"。
>
> **[9]** 报告汇总的是过程证据：诊断、任务、实验、笔记。三个导出按钮，Markdown、JSON、打印。
>
> **[10]** 教师端。左边是 AI 建议分，右边是复核最终分。AI 给参考，最终分永远由老师给，并覆盖建议值。
>
> **[11]** 这是我们对 OpenMAIC 的核心改造：在应用层注入一套大学物理的领域约束——符号量纲、常见误区、实验安全、课程思政。
>
> **[12]** 一次注入，贯穿课件、测验、仿真、白板演算和项目式学习，而且没有改动上游任何生成模板。
>
> **[13]** 导出的 PPTX 每页都带着校名：贴顶是页眉，贴底是页脚，可以直接进讲台。
>
> **[14]** 最后一点很重要：断网、额度用完，这个平台照样能完整演示。真实模型、本地确定性引擎、预生成课程包，三级降级。
>
> **[15]** 感谢清华大学开源团队提供的 OpenMAIC。长江大学文理学院《大学物理》课程团队。
