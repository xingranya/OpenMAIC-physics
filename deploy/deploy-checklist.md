## I2. 自定义域名与 TLS 证书（评委若从 `dun.xran.uk` 进入，这一节不过就是致命）

- [ ] DNS 记录已加且生效：CNAME `dun` → `dun.xran.uk.pages.dnsoe6.com`（**仅 DNS / 灰色云，不要代理**）
      核验：`dig +short CNAME dun.xran.uk` 应回 `dun.xran.uk.pages.dnsoe6.com`
- [ ] 路由已通：`curl -o /dev/null -w '%{http_code}' http://dun.xran.uk/` 应为 200
- [ ] ⚠️ **HTTPS 证书已为该域名签发**——这一条最容易漏：
      域名「绑定成功 + DNS 生效」**不等于**证书已签发。证书没签发时，
      边缘仍会下发**共享的 CDN 证书**（`CN=*.cdn.myqcloud.com`），
      浏览器打开就是证书错误，评委看到的是「网站打不开」。
      核验：`echo | openssl s_client -connect dun.xran.uk:443 -servername dun.xran.uk 2>/dev/null | openssl x509 -noout -subject`
      证书的 CN/SAN 里必须出现 `dun.xran.uk`；只有 `*.cdn.myqcloud.com` 就是**还没签发**。
- [ ] 证书签发路径（**控制台**操作，命令行/CLI 都没有对应命令）：
      `控制台 → EdgeOne → Makers → 项目 physics-ai-classroom-global → 域名管理`
      → 找到 `dun.xran.uk` 这一行 → **「HTTPS 配置」列**（当前显示「未配置」）
      → 点该列的「**配置**」→ 弹出「边缘 HTTPS 证书」面板 → 选免费证书并申请
      → 等待签发（DNS 验证通过后平台也会自动签发，分钟级到小时级）
- [ ] 证书就绪后**再**考虑打开同一面板里的「强制 HTTPS」与「HSTS」——
      证书没好之前开强制 HTTPS，会把 HTTP 访问重定向到不可用的 HTTPS，反而更糟
- [ ] 签发后用**开启证书校验**的方式复验（不要用 `curl -k` 掩盖问题）：
      `curl -o /dev/null -w '%{http_code}' https://dun.xran.uk/` 应为 200

## K. 部署后必做的"活不活"自检（5 分钟，最容易被忽略的一步）

> 这一节针对一个真实踩过的坑：构建成功（EXIT=0）**不等于**页面点得动。
> 若客户端 chunk 有任何一个非 200，React 不会水合，页面 SSR 文字完全正常，
> 但**所有按钮静默失效**——现场就是"点了没反应"。

- [ ] 跑一次自动化自检：`node scripts/check-physics-e2e.mjs --base-url <线上地址> [--access-code <口令>]` → **未启用口令 21 项 / 启用口令 25 项全通过**
- [ ] ⚠️ **BUILD_ID 一致性核对**（本地/自托管必做）：页面 HTML 引用的客户端 chunk
      与磁盘上的 `.next/BUILD_ID` 同源同版本。重建过产物却没重启服务时，
      旧 HTML 会引用已被删除的 chunk → 页面文字正常但按钮全哑。
      线上（EdgeOne 托管）无需此项，但**本地验证必须重启进程后再跑自检**
- [ ] ⚠️ **清理残留的本地服务进程**（本地演示必做）：`lsof -nP -iTCP -sTCP:LISTEN | grep node`
      确认只留**一个**实例。残留的旧实例会让验证跑在老代码上，
      改过 `BUILD_ID` 的代理还会让上一项**误判通过**（见 `deploy/README.md` §8.5）
- [ ] 线上首页能打开，浏览器 Console **无红色 error**
- [ ] 点一下任意按钮（如首页「物理学习工作台」入口），**确认有反应**
- [ ] 学生端一键入口（`/login?demo=student`）能进入工作台
- [ ] 教师端一键入口（`/login?demo=teacher`）能进入教师驾驶舱
- [ ] 口令弹窗：输入 `ACCESS_CODE` 后能真正放行（不是反复弹回）
- [ ] 预置包导入后能进入课堂并播放
- [ ] 预置包的 **PBL 项目任务场景**渲染出真实项目（不是「PBL项目尚未生成」占位）
- [ ] 预置包的 **白板演算**能画出公式
